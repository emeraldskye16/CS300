# CS300
What was the problem you were solving in the projects for this course?

The main problem I was addressing in the projects for this course was the effective management and organization of course data. Specifically, the goal was to create a system that could easily load, store, and retrieve course information, including titles, course numbers, and prerequisite courses. By implementing a data structure that meets these requirements, I aimed to provide an efficient way to validate course prerequisites and to enable users to access course details easily.


How did you approach the problem? Consider why data structures are important to understand.

To address this problem, I focused on utilizing various data structures, primarily vectors, hash tables, and binary search trees. Understanding these structures is crucial because they directly affect performance and resource management in software applications. For instance, vectors offer dynamic sizing and simple access methods, while hash tables provide efficient key-value pairing for quick lookups. By choosing the proper data structure for the specific tasks, I optimized the operations needed to manage course data effectively.


How did you overcome any roadblocks you encountered while going through the activities or project?

During the development process, I encountered several roadblocks, including difficulties validating prerequisite courses against the existing course list and ensuring that data was correctly loaded from external files. To overcome these challenges, I utilized debugging techniques and detailed logging to track data flow and pinpoint issues. I also consulted documentation and sought advice from peers when tackling more complex aspects of the project, which helped me gain different perspectives on problem-solving.


How has your work on this project expanded your approach to designing software and developing programs?

Working on this project has significantly expanded my approach to software design. I learned to think critically about which data structures and algorithms best fit specific problems. For instance, when implementing a hash table for quick course lookups, I realized the importance of efficient data retrieval, especially for larger datasets. This experience has taught me continually to consider performance implications when designing software, leading to better decision-making in future projects.


How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

My work on this project has evolved my programming practices, particularly in terms of maintainability, readability, and adaptability. By adhering to clear coding standards and structuring my code logically, I have developed a more organized coding style. I've learned the value of documenting functions clearly and using descriptive variable names, which makes it easier for others (and my future self) to understand the code. This project has emphasized the importance of writing code that can be easily modified and extended, preparing me for real-world software development, where changes and updates are constant.

In summary, reflecting on these experiences has reinforced my understanding of data structures and their practical applications, while helping me grow as a programmer committed to writing clean, efficient code.
